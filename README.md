# GuildMarket

Guild-internal marketplace for **Der Hohe Rat** — post WTB/WTS listings that automatically sync to all online guild members.

Created by **MichaModus**

---

## Features

- Post **Suche** (WTB) and **Biete** (WTS) listings for crafting materials and items
- Listings automatically sync to all online guild members with the addon installed
- Filter by Alle / Suche / Biete
- Tooltip shows full note and contact name on hover
- Entries expire after **7 days** automatically
- Delete your own listings with the ✕ button
- No server required — peer-to-peer sync via WoW addon messages

## How it works

When you log in, the addon broadcasts your active listings to the guild channel. Other players with GuildMarket installed receive and cache them locally. Click **↻ Sync** to request all listings from currently online guild members.

## Commands

| Command | Action |
|---|---|
| `/gmarkt` | Open / close the marketplace |
| `/gildenmarkt` | Open / close the marketplace |
| `/gmarkt sync` | Request sync from all online members |

## Setup

Copy the `GuildMarket` folder to `World of Warcraft/_anniversary_/Interface/AddOns/`
